# MatchMind static demo

Public, zero-key snapshot of **MatchMind**, a real-time explainability layer for
football broadcast.

## Open the demo

- Studio: <https://ruziniuuuuu.github.io/matchmind-demo/#/studio>
- Overlay: <https://ruziniuuuuu.github.io/matchmind-demo/#/overlay?bg=1&template=stat_card>
- Guide: <https://ruziniuuuuu.github.io/matchmind-demo/#/guide>
- Fan: <https://ruziniuuuuu.github.io/matchmind-demo/#/fan?match=ast-2026-1025-vel-kep>
- 2-minute promo: <https://ruziniuuuuu.github.io/matchmind-demo/promo.mp4>
- Quick walkthrough: <https://ruziniuuuuu.github.io/matchmind-demo/demo.mp4>

## What works here

- Five synthetic fixtures with cached, verified insights
- Broadcast Studio with agent rundown, evidence, replay, and five overlay templates
- Transparent OBS overlay variants
- Personalized Fan views in English, Spanish, and Chinese
- Player focus event log and deterministic match recap

The static build intentionally disables live model generation and the WebSocket
feed. The full five-agent Microsoft Agent Framework graph, MCP analytics server,
live replay, retries, and deterministic verifier run in the source application.
