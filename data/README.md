# MatchMind synthetic demo data

`data/demo/` contains five deterministic, fully synthetic football matches
generated by MatchForge. They use fictional clubs, fictional players, and no real
match footage, event data, club crests, or player likenesses.

## Generate

```bash
make data
# or a single match:
uv run python -m matchmind.matchforge --match ast-2026-1018-nhr-orn
```

The generator is deterministic: the same seed and generator version produce the
same event stream.

## Files

| File | Contents |
|---|---|
| `events.jsonl` | One JSON event per line |
| `match.json` | Match metadata, teams, lineups, final score |
| `labels.json` | Ground-truth key moments for evaluation only |

## Event shape

```json
{
  "match_id": "ast-2026-1018-nhr-orn",
  "event_id": "e-001011",
  "ts": "2026-10-18T16:12:09Z",
  "clock": {"period": 2, "minute": 72, "second": 9},
  "type": "pass",
  "team_id": "NHR",
  "player_id": "NHR-08",
  "location": {"x": 38.0, "y": 52.0},
  "end_location": {"x": 62.0, "y": 44.0},
  "recipient_id": "NHR-14",
  "pressure": 0.82,
  "outcome": "complete",
  "ball_speed_kmh": 18.4,
  "distance_m": 24.6,
  "difficulty": 8.7,
  "possession_id": "p-hero",
  "score": {"home": 1, "away": 1},
  "tags": ["line_break", "under_press", "hero"],
  "synth": {"seed": 20261018, "generator": "matchforge-v1"}
}
```

- Pitch coordinates are normalized `x: 0-100` (attacking direction) and
  `y: 0-100`.
- `pressure` is `0-1`.
- `difficulty` is a 0-10 pass-difficulty rating.
- `xG`, `xT`, control, chaos, and momentum are **not** stored in the event
  stream; the deterministic analytics engine computes them from events.

## Labels

`labels.json` contains only evaluation ground truth for key moments (goals,
cards, sprints, the 72' line break). Labels are never passed to the agents.
