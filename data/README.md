# MatchMind synthetic demo data

`data/demo/ast-2026-1018-nhr-orn/` is a deterministic, fully synthetic football
match generated by MatchForge. It contains fictional clubs, fictional players,
and no real match footage, event data, club crests, or player likenesses.

## Generate

```bash
make data
# or
uv run python -m matchmind.matchforge --seed 20261018
```

The generator is deterministic: the same seed and generator version produce the
same event stream.

## Files

| File | Contents |
|---|---|
| `events.jsonl` | One JSON event per line (1,300+ events) |
| `match.json` | Match metadata, teams, lineups, final score |
| `labels.json` | Ground-truth key moments for evaluation only |

## Event shape

```json
{
  "match_id": "ast-2026-1018-nhr-orn",
  "event_id": "e-000842",
  "ts": "2026-10-18T16:12:14+00:00",
  "clock": {"period": 2, "minute": 72, "second": 14},
  "type": "pass",
  "team_id": "NHR",
  "player_id": "NHR-08",
  "location": {"x": 38.2, "y": 51.7},
  "end_location": {"x": 61.9, "y": 44.1},
  "recipient_id": "NHR-14",
  "pressure": 0.82,
  "outcome": "complete",
  "ball_speed_kmh": 18.4,
  "distance_m": 24.6,
  "difficulty": 8.7,
  "possession_id": "p-hero",
  "score": {"home": 1, "away": 1},
  "tags": ["line_break", "under_press", "hero"],
  "synth": {"seed": 20261018, "generator": "matchforge-v0.1"}
}
```

- Pitch coordinates are normalized `x: 0-100` (own goal to opponent goal) and
  `y: 0-100`.
- `pressure` is `0-1`.
- `difficulty` is a 0-10 pass-difficulty rating.
- `xG`, `xT`, control, chaos, and momentum are **not** stored in the event
  stream; the deterministic analytics engine computes them from events.

## Labels

`labels.json` contains only evaluation ground truth for key moments (goals,
the 72' line break, the 31' sprint). Labels are never passed to the agents.
